# Nectar steam studies

These are original code-native SVG explorations extending the established logo system. No image generation, raster design editing, site tooling, or checkout edits were used.

- `a-ribbon.svg` — a tall, narrow double-contour ribbon, lifting in a soft S and tapering as it drifts right.
- `b-drift.svg` — a lower, broader cohesive body, peeling right into open air, with a restrained internal contour.
- `c-curl.svg` — a fuller calligraphic body with a gentle return curl and softly tapered tip.
- `comparison.svg` — annotated three-up comparison, 1800 × 650.

Each standalone is 600 × 540, with the same rectangular frame, ivory on #161712, serif Nectar wordmark, and graphic above the name. The base path from `#nectar-key` is preserved verbatim through the handle; the previous steam command is the only omitted geometry. The base stroke weight is also unchanged at 2.1 in logo units. New steam is a single bounded contour with a fine internal contour, rather than three disconnected stock wisps.

Reference sources read: `docs/brand-guide.md`, the `#nectar-key` symbol in `public/index.html`, and `design-assets/brand-reference/nectar-original-logo.webp` (visually inspected).

No variant has been applied to the site. These are choice studies for user review.
