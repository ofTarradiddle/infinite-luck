# Cloud and unwinding steam studies

Logo concepts responding to the request for more cloud-like, unwinding steam. Created with the built-in imagegen edit tool, one call per concept; the original brushed logo was the edit target. The owner selected **B — Unwinding Haze**, now used on the website and packaging. A remains an archived alternative.

- [A — Rolling Cloud](a-rolling-cloud.png): a broad cloud body with layered rolling eddies. [Exact prompt and inspection](a-rolling-cloud-prompt.md).
- [B — Unwinding Haze](b-unwinding-haze.png): a single open sweeping curl with loose brush edges. [Exact prompt and inspection](b-unwinding-haze-prompt.md).
- [Side-by-side comparison](comparison.png). The comparison only arranges scaled copies of the full original previews.
