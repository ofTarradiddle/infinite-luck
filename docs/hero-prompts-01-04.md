# Nectar hero series — images 01–04

Each image was generated independently with the built-in `image_gen.imagegen` tool, one call per image, using generation mode, no reference image, and `transparent_background: false`. No API key or fallback CLI was used. Each selected output was visually inspected. All four images are **1536 × 1024**, opaque RGB, landscape 3:2.

Public assets were encoded as WebP with Pillow, quality 91 and method 6, with no creative editing, cropping, compositing or color adjustment. Originals remain in the project for future adaptation.
